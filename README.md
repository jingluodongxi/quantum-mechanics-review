# 量子力学第二、三章复习网站

简体中文的静态学习网站，包含 16 节课程和 64 道题。题库收录 16 道勾选的教材习题、6 道云课堂作业题和 42 条期中试卷及回忆题。课程从前置数学知识讲起，题目按原题号标注来源，提供逐步提示、详细解析和考场写法。

[打开公开学习网站](https://jingluodongxi.github.io/quantum-mechanics-review/)

## 本地使用

在仓库根目录运行以下命令，然后打开浏览器访问 `http://127.0.0.1:8000`。

```sh
python -m http.server 8000 --bind 127.0.0.1 --directory dist
```

也可以把 `dist/` 作为静态网站目录部署。KaTeX 及字体已包含在仓库中，公式在浏览器里排版。草稿、错题和学习进度使用浏览器本地存储。
